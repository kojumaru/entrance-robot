========================================
精密Lab. 受付・案内ロボット 仕様書
========================================
作成日: 2026-03-20
対象イベント: 東大五月祭「精密Lab.」展示

----------------------------------------
1. プロジェクト概要
----------------------------------------
来場者を迎え入れ、展示内容や企画場所を音声と画面で案内するロボットシステム。
ノートPC上で動作し、マイク・スピーカー・モニターを使って来場者と対話する。

----------------------------------------
2. ハードウェア構成
----------------------------------------
- PC: MacBook Air (M1, macOS 14)
- 入力: マイク（内蔵 or 外付け）
- 出力: スピーカー（音声）、外部モニター（マップ表示）
- 操作: キーボード（スペースキーでモード切替）

----------------------------------------
3. 動作モード
----------------------------------------

【A. 待機モード (STANDBY)】
- 10〜15秒ごとにランダムな呼び込みメッセージを音声で発話
- 現在の呼び込みメッセージ:
    ・「精密ラボへようこそ！1階右と3階で工学のさまざまな企画を展示しています！」
    ・「こんにちは！精密ラボの展示をご案内します！」
- pygameウィンドウは待機状態（前回表示したマップがそのまま表示）

【B. 対話モード (INTERACTION)】
- 「こんにちは！何かご質問はありますか？」と発話してマイク待機
- 来場者の発話を認識 → Geminiで回答生成 → 音声で返答
- 企画場所を質問された場合、該当箇所に赤丸を描いたマップをモニターに表示
- 8秒間無音が続いた場合、自動的に待機モードへ復帰

【モード切替トリガー】
- 現在: スペースキー（pygameウィンドウにフォーカスが必要）
- 将来: YOLOによる人物検知（別チームが実装予定）

----------------------------------------
4. 技術構成
----------------------------------------

【音声認識】
- ライブラリ: SpeechRecognition
- エンジン: Google STT（無料、APIキー不要）
- 言語: 日本語 (ja-JP)
- マイク感度閾値: 300（騒がしい環境では500〜1000に調整）
- タイムアウト: 8秒

【AI対話】
- API: Google Gemini API (google-genai)
- モデル: gemini-2.5-flash-lite（変更可）
- 入力: システムプロンプト + ユーザー発話テキスト + マップ画像2枚
- 出力: JSON形式 {"speech": "発話テキスト", "location": {...} or null}

【音声合成】
- ライブラリ: gTTS (Google Text-to-Speech)
- 言語: 日本語
- 再生: pygame.mixer

【マップ表示】
- PDFファイル: assets/企画場所.pdf（2ページ）
    - 1ページ目: 1Fフロア（プロ室、休憩室、ミツトヨエリア等）
    - 2ページ目: 3Fフロア（倒立振子、ARタンク、PONGエリア等）
- PDF→画像変換: PyMuPDF (dpi=150)
- 丸印描画: PIL (Pillow)
- 表示: pygame（1200×700px ウィンドウ）

【座標指定方式（現状）】
- GeminiがJSONで座標を返す
    {"page": 1, "x": 0.65, "y": 0.15}  ← 相対座標 (0.0〜1.0)
- 問題点: Geminiの推測に依存するためズレが生じる場合がある
- 改善案（未実装）: 企画ごとに座標を手動登録した辞書を用意し、
  Geminiには「どの企画か」のみ判定させる方式

----------------------------------------

----------------------------------------
8. 起動方法
----------------------------------------
$ python main.py

操作:
- スペースキー : 待機モード ↔ 対話モード切替
- ESCキー / ウィンドウを閉じる : 終了

10. Geminiへのシステムプロンプト仕様
----------------------------------------
- 役割: 精密Lab.の受付・案内ロボット
- 応答形式: JSON固定
    {
      "speech": "読み上げテキスト（3文以内）",
      "location": {"page": 1, "x": 0.5, "y": 0.3} or null
    }
- 制約: 展示に無関係な質問には「展示に関するご質問をどうぞ」と返す
